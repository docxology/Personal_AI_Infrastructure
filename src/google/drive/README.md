# Google Drive

**Category**: Content creation and storage
**URL**: [https://drive.google.com](https://drive.google.com)

## Overview
**[IMPLEMENTED]**
This module provides a fully functional Python client for Google Drive, powered by the `@dav23/google-mcp` server.

### Features
- List files
- Create folders
- Upload files
- Update file content
- Share files

### Authentication
Uses `~/.claude/google-calendar/google_services_token.json`.
