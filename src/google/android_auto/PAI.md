# Android Auto - PAI Integration

## PAI Context

This service module provides PAI with access to Google Android Auto functionality.

## Client Access

```python
from google.android_auto.client import AndroidAutoClient
```

## Authentication

Uses PAI's centralized Google credentials at `~/.claude/google-calendar/`.
