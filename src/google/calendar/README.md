# Google Calendar

**Category**: Communication and collaboration
**URL**: [https://calendar.google.com](https://calendar.google.com)

## Overview
**[IMPLEMENTED]**
This module provides a fully functional Python client for Google Calendar, powered by the `@cocal/google-calendar-mcp` server.

### Features
- List calendars
- List events
- Create events
- Update events
- Delete events

### Authentication
Uses `~/.claude/google-calendar/token.json`.
