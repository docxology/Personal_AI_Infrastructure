# Google Tasks

**Category**: Communication and collaboration
**URL**: [https://tasks.google.com](https://calendar.google.com) (Integrated into Calendar/Gmail)

## Overview
**[IMPLEMENTED]**
This module provides a fully functional Python client for Google Tasks, powered by the `@dav23/google-mcp` server.

### Features
- List task lists
- Manage tasks (create, update, delete, complete)

### Authentication
Uses `~/.claude/google-calendar/google_services_token.json`.
