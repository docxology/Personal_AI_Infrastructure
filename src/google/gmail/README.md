# Gmail

**Category**: Communication and collaboration
**URL**: [https://mail.google.com](https://mail.google.com)

## Overview
**[IMPLEMENTED]**
This module provides a fully functional Python client for Gmail, powered by the `@dav23/google-mcp` server.

### Features
- List threads and emails
- creating drafts
- Sending emails
- Managing labels
- Downloading attachments

### Authentication
Uses `~/.claude/google-calendar/google_services_token.json`.
