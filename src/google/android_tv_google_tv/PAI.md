# Android Tv Google Tv - PAI Integration

## PAI Context

This service module provides PAI with access to Google Android Tv Google Tv functionality.

## Client Access

```python
from google.android_tv_google_tv.client import AndroidTvGoogleTvClient
```

## Authentication

Uses PAI's centralized Google credentials at `~/.claude/google-calendar/`.
