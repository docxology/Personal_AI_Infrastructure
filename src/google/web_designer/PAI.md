# Web Designer - PAI Integration

## PAI Context

This service module provides PAI with access to Google Web Designer functionality.

## Client Access

```python
from google.web_designer.client import WebDesignerClient
```

## Authentication

Uses PAI's centralized Google credentials at `~/.claude/google-calendar/`.
