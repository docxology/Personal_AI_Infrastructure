# Gemini For Google Workspace - PAI Integration

## PAI Context

This service module provides PAI with access to Google Gemini For Google Workspace functionality.

## Client Access

```python
from google.gemini_for_google_workspace.client import GeminiForGoogleWorkspaceClient
```

## Authentication

Uses PAI's centralized Google credentials at `~/.claude/google-calendar/`.
